Drag vertically along the internet-use axis to select a gain range. Click an axis title to move it one position. Blue lines are selected countries; gray lines retain the rest of the 175-country sample. Three named examples are highlighted when selected.

Above zero means increase; below zero means decrease. Each axis has its own range. Bundling groups the selected and remaining records separately, preserves measured axis intersections, and uses a 20% bend. These groups are user selections, not discovered clusters. Changes describe reported indicators, not causes or unique mobile users.
